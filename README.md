# dangus
dangus creates a world node tree.  
Sky image textures are blended seamlessly and can be combined with cloud decals and a fog gradient into sky layers. A sun layer can relight the sky. All layers can be animated, baked, and exported as a sky dome.

**This repository is a part of Blender addons developed for the short animated movie MALDA**
